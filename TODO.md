# TODO: прототип «О!дин шаг до идеального отеля»

Сдача 29.10.2026 10:00 МСК. Регион: центр Сочи. Принцип: LLM пишет рецепты и разбирает текст, считает код.

## Как устроено (коротко)

- `data/`: демо-данные в репозитории (отели Островка в зоне, вырезка OSM, карта высот, климат), скрипты пересборки в `scripts/`.
- `app/tools/`: общие примитивы (рядом по тегам OSM, пеший путь с подъёмом и переходами, горизонт и видимость моря по этажам, солнце, шум, открыто ночью, климат, отзывы с цитатами, карточка).
- `registry/*.yaml`: характеристики. Каждая = текстовое описание + рецепт (вызовы примитивов + выражение значения + уверенность + TTL + вопрос отельеру).
- `app/compiler.py`: новая характеристика текстом → LLM пишет рецепт → проверка схемы → пробный прогон → в реестр.
- `app/store.py`: SQLite с фактами (источник, метод, уверенность, дата, срок годности, улики, хэш входов), резолвер конфликтов.
- `app/search.py`: запрос словами → ограничения по реестру → три корзины (подходит / не знаем / не подходит) + объяснения.
- `app/mcp_server.py`: всё это как MCP-инструменты. Веб-чат — один из клиентов.
- `app/web/`: чат-поиск, карточка с фактами и провенансом, сравнение, кабинет отельера, реестр, метрики.
